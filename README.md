## Почему добавлен второй CSV-файл в задании 2 (russian_beasts.csv)

Исходное задание предусматривало парсинг Википедии по алфавиту животных и сохранение результатов по буквам в CSV-файл. Однако при выполнении задачи оказалось, что:

- В итоговом beasts.csv учитываются все встречающиеся первые буквы (в том числе латинские, цифры, символы), а не только буквы русского алфавита.
- В ряде случаев на странице встречаются животные, названия которых начинаются на латинские буквы (например, Xenopus), цифры или необычные знаки.

Чтобы обеспечить дополнительную аналитическую ценность и удобство анализа, был создан дополнительный файл — russian_beasts.csv, в котором содержится статистика исключительно по буквам русского алфавита (А–Я и Ё). Это позволяет:

- Получить корректную статистику по основному русскому алфавиту, исключив "шумовые" записи.
- Сравнить распределение животных с русскими названиями и прочими.
- Упростить интеграцию данных для работы в учебных, исследовательских и других задачах, где интересны животные именно с русскими именами.

Вывод:  
Дополнительный CSV-файл — не отход от задачи, а расширение её пользы. Основной файл (beasts.csv) сохраняет всю собранную статистику, а russian_beasts.csv выводит "чистую" статистику только по русским буквам, что удобно для большинства анализов.
